# Project X-Core　／　蒼藍核心

原創科幻像素橫向捲軸動作 RPG。向經典 16-bit／NDS 風格側視動作遊戲致敬，但**並非官方洛克人作品**，亦無使用任何官方角色、精靈圖、音樂或盜用素材。

你扮演一位原創像素獵人（根據提供相片繪製：卷发、白色唐裝領襯衫、黑色長褲、赤褐色運動鞋、前臂青色手砲，沒有頭盔），喺陽光海灘關卡裡衝刺、跳躍、探索學習站、收集裝甲零件同晶片，最後挑戰多階段首領「潮汐巨蟹」。畫面係開心嘅晴天沙灘（原創 NDS 密度像素遠景），沿途敵人係可愛小動物，並無使用任何官方洛克人／Zero／ZX 精靈圖、圖塊、HUD 或音樂。蹬牆跳仍然可用作捷徑，但主路、五個學習站同沿途零件都可以用普通跳躍到達。

本遊戲對齊香港小學二年級科學、校本 2627 學段二課題，供課堂探索練習，**勿直接當評核試卷**。

## 點樣遊玩

本機開發：

```bash
npm install
npm run dev
```

瀏覽器打開 Vite 顯示嘅本機網址即可。建議用鍵盤或 iPad Safari（有螢幕虛擬按鈕）。

建置靜態檔：

```bash
npm run build
npm run preview
```

輸出喺 `dist/`，可用任何靜態空間托管。

### 鍵盤

| 按鍵 | 動作 |
| --- | --- |
| 方向鍵 或 A／D | 左右移動 |
| Z、空白鍵 或 ↑／W | 跳躍；貼牆時為蹬牆跳（可同時按住衝刺作大跳） |
| X（長按再放） | 三段蓄力手砲：輕點／中蓄／滿蓄（滿蓄可喺擊破目標時貫穿） |
| C | 衝刺（地面或牆上；裝上「空躍腿甲」後每次跳躍可空中衝刺一次） |
| E | 打開／關閉裝備介面（遊戲會暫停） |

### 觸控（iPad Safari）

畫面左下為虛擬方向鍵，右下為「跳／射／衝」，右上為「裝」。可以同鍵盤一齊用。

### 裝備同升級

- 裝甲槽：頭盔、胸甲、手臂、腿部。開局已裝備標準套裝。
- 晶片槽：2 個，全部係被動效果。
- 關卡物件層放有額外零件／晶片，碰到就會放入背包，按 E 裝備。
- 數值會即時生效（生命、攻擊、蓄力速度、減傷、燈光範圍、空中衝刺、回血、對首領傷害、無敵時間、雙發等）。
- 擊敗敵人同首領會獲得經驗，升級會提升生命上限同攻擊。

### 學習站（二年級科學｜學段二）

沿途有 5 個學習站，分別對齊校本課題：**聲動**、**齊心合力**、**磁向南北**、**產品大解構**、**天氣日記**。走近學習站，重疊時會自動打開一次提問卡，之後再訪可按「跳」繼續練習。

- 每站會從題庫抽出一題尚未答過嘅題目（每課題約 3–4 題，合共 20 題），三選一，字體同按鈕都偏大，方便 iPad 點擊。
- 答對會看到一句解釋、加「科學分」，並可用瀏覽器語音（`zh-HK`）讀出關鍵生字；答錯會得到提示，可以再試，唔會卡住，亦唔會責罵。
- 畫面會顯示科學分同學習站進度（例如「學習站 2/5」）。
- 要先喺五個課題都至少答對一題，先可以打開首領門挑戰「潮汐巨蟹」。如果提早走到門前，會有友善提示，請先完成學習站。

呢部分係課堂練習／探索，不是測驗，沒有考試記分用意。

### 關卡同首領

陽光海灘由左至右推進。地圖係真實 Tiled 1.x JSON（`public/assets/maps/stage1.json`），以 Phaser 嘅 tilemap 載入器讀取。關卡有分層晴空／海面／棕櫚遠景，同原創沙地、木棧道圖塊。原有碰撞佔位同物件位置維持不變，另外加咗踏腳平台，令主路同學習站唔需要蹬牆跳都可以上去。

關卡盡頭係首領擂台。完成五個學習站後，踏入觸發區鏡頭會鎖喺擂台，「潮汐巨蟹」分三階段戰鬥：

1. 巡邏、砲火齊射、跳躍同角撞。
2. 約三分二血量：加速、橫向衝撞、地面震擊彈。
3. 約四分一血量：絕望模式（落彈＋螺旋彈＋衝撞），外觀會有電光光環。

擊破後會得到經驗值同獨特零件「潮汐甲盔」，並顯示過關訊息。如果戰鬥中力盡，按「跳」可以在擂台入口重新起動（首領會重置，已有裝備同等級會保留）。

## GitHub Pages

專案已包含 `.github/workflows/deploy.yml`（Node 20、`npm ci`、`vite build`、upload-pages-artifact、deploy-pages）。`vite.config.ts` 已設 `base: './'` 同 `assetsInlineLimit: 0`，並附有 `public/.nojekyll`。

要發佈時：將本資料夾推到 GitHub 倉庫嘅 `main` 分支，然後喺倉庫 Settings → Pages，將 Source 設為 GitHub Actions。推送後約數十秒，就可以用：

`https://<帳戶>.github.io/<倉庫名>/`

嵌入 Google Sites：選「嵌入」→「依網址」，貼上面呢條即可。

**注意：** 本次係本機更新（陽光海灘、踏腳平台、小動物敵人、潮汐巨蟹、點陣介面字）。線上 GitHub Pages 尚未同步，需要稍後另一步先推送更新。
